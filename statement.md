# Project Statement

## Project Title
Library Management with Fine Calculation & Reservation Queue

## Problem Statement
Manual or fragmented library workflows make it difficult to maintain catalogue records, track due dates, calculate overdue fines consistently, and manage demand for unavailable books. This project provides a terminal-based system that centralizes these workflows.

## Scope
Catalogue CRUD, authentication, role-based authorization, issue/return, automatic fines, priority reservations, reports, SQLite persistence, validation, and tests.

Out of scope: online payments, email/SMS, barcode hardware, and GUI.

## Target Users
- Admin
- Librarian
- Member

## High-Level Features
- Catalogue CRUD
- Issue/return and fine engine
- Reservation queue
- Role-based access
- Reports
- SQLite persistence
- Automated tests
